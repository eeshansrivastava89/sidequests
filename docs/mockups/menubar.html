Design & Architecture Decisions

Thin Client, Thick Server

The menu bar app is a notification client + quick-gesture launcher. It polls localhost:PORT/api/ for data. All logic lives in the existing Sidequests web server. No GitHub API calls, no LLM calls, no database — the menu bar app is just a SwiftUI view layer.

What It Shows

Badge: count of items needing attention. Dropdown: top 4 "What Now?" actions + stale projects needing decisions. Not a full dashboard — that's what the web UI is for. "Open Dashboard" button at the bottom opens localhost:PORT.

Notifications

Uses macOS UNUserNotificationCenter via node-notifier from the server process — no app install needed for basic notifications. The menu bar app adds badge counts, snooze controls, and stale project decisions.

Why Not RepoBar?

RepoBar is a mature 15K-line Swift app for GitHub monitoring. We'd rip out 90% of it (auth, GraphQL, caching) to replace with HTTP calls to localhost. Writing a thin ~800-line Swift menu bar client from scratch is faster and simpler. Its patterns (MenuBarExtra, settings panels) are good reference material.

Snooze & Lifecycle

The menu bar adds the decision layer: right-click or long-press a stale project to snooze (1h / 1d / 1w / 2w), revive ("I'm back"), or archive ("I'm done"). These lifecycle actions sync back to the server and update the dashboard.

Distribution

Menu bar app: signed macOS .app bundle, distributed via brew install --cask sidequests or DMG download. No Sparkle auto-update needed (small binary, infrequent changes). Web dashboard still distributed via npx.

Implementation Stack
Menu Bar Companion
Language: Swift 6.2 + SwiftUI + AppKit
UI: MenuBarExtra (left-click dropdown, right-click menu)
Data: HTTP polling to localhost:PORT/api/ (every 5 min)
Notifications: UNUserNotificationCenter for macOS alerts
Size: ~2MB binary, zero external deps
Dist: Homebrew cask or DMG
Web Dashboard (existing)
Server: Next.js → Hono (after migration)
Build: Vite SPA
Notifications: node-notifier (macOS native, no app needed)
CLI: sq status / sq next / sq focus
Dist: npx @eeshans/sidequests
